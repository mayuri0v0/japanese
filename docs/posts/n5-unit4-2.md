# TRY! N5 Unit 4(2)

## ２０　「アメ横」というところ

A という B: 所谓的..., B用于描述A

A という A: 所有的...



## ２１　「アメ横」は安い店が多いです

”AはBが～”, 表示A这一整体中的B这一局部特征



## ２２　安くて美味しいです

连续使用形容词/名词时, 使用て形, 过去发生的事同样

|          | 敬体形                        | て形                 |
| -------- | ----------------------------- | -------------------- |
| い形容词 | +です                         | 词尾"い"变"くて"     |
|          | 词尾"い"变"くない"+です       | 词尾"い"变"くなくて" |
| な形容词 | +です                         | +で                  |
|          | +ではありません／じゃないです | +じゃなくて          |
| 名词     | +です                         | +で                  |
|          | +ではありません／じゃないです | +じゃなくて          |

只用于顺承, 不用于逆接
