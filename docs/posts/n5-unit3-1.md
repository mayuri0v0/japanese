# TRY! N5 Unit 3(1)

## ８　電子辞書ですね

”ね”寻求认同, 确认



## ９　きのう買いました

表示过去发生的事情时, 使用”～でした””～ました”

|          | 现在肯定形              | 现在否定形                              |
| -------- | ----------------------- | --------------------------------------- |
| 动词     | ～ます→～ました         | ～ます→～ませんでした                   |
| い形容词 | 词尾"い"变"かった"+です | 词尾"い"变"くなかった"+です             |
| な形容词 | +でした                 | +ではありませんでした／じゃなかったです |
| 名词     | +でした                 | +ではありませんでした／じゃなかったです |





## １０　ほしいです

表达自己想要某物, 使用”～がほしいです”, 不用于表达他人的意志

名词 + が + ほしいです

愿望/能力/喜恶 使用”が”引出对象
