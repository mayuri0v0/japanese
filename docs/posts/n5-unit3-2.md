# TRY! N5 Unit 3(2)

## 动词分类

| 来る／する      | 三类动词(カ变／サ变)   |
| --------------- | ---------------------- |
| 词尾不是る      | 一类动词(五段)         |
| い段／え段+る   | 大部分是二类动词(一段) |
| あ、う、お段+る | 一类动词(五段)         |



## 动词‐ます形

### 一类动词

う段变い段+ます

### 二类动词

去掉る+ます

### 三类动词

する→します

くる→きます



## 动词‐て形

### 一类动词-音便

| 结尾       |             |
| ---------- | ----------- |
| く         | 变い+て     |
| ぐ         | 变い+で     |
| う、つ、る | 变っ+て     |
| む、ぶ、ぬ | 变ん+で     |
| す         | 去掉す+して |

### 二类动词

去掉る+て

### 三类动词

する→して

くる→きて



## １１　駅まで行って、…

连续表达几个动作时, 使用て形

表示过去的句子时也一样使用て形



## １２　バスで行きました

凭借某种交通方式或工具时, 使用”～で”

名词+で



## １３　どこか行きましたか

非特指地表达人, 事物, 地点. 即询问行为本身时, 在疑问词后加”か”

| どこか | somewhere |
| ------ | --------- |
| なにか | something |
| だれか | somebody  |

どこへ行きましたか：

特殊疑问句, 回答地点

どこか（へ）行きましたか：

一般疑问句, 询问是否发生了"去某处"这件事, 去哪里不重要



助词”か””を””へ”可以省略, 其他助词不能省略(影响句意)



## １４　どこへも行きません

疑问词+も+～ない, 强调完全没有



必须省略助词”か””を”, 可以省略助词”へ”, 其他助词不能省略(影响句意)
