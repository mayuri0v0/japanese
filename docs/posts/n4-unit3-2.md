# TRY! N4 Unit 3(2)

## １７　誰が参加してもいい

「～てもいい」, 就算做了...也没关系

て形+もいい



## １８　どんなものをあげるんですか

「あげる」, 表示给予

「もらう」, 表示接受

「くれる」, 表示给我

A+は／が+B+に～をあげる：A给B...

A+は／が+B+に～をもらう：A从B处得到...

A+は／が(+B+に)～をくれる：A给我(我方人员)...



「てあげる」「てもらう」「てくれる」同理



## １９　あげなくてもいい

「～なくてもいい」, 没必要做...

ない形词干+なくてもいい



## ２０　あげたほうがいい

「～たごうがいい」, 表示建议

た形／ない形+ほうがいい



## ２１　あげることにします

「～ことにします」, 按自己的意愿决定做..

原形／ない形+ことにする
