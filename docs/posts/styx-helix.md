## Verse 1 主歌

> <ruby>狂<rt>くる</rt></ruby>った<ruby>時計<rt>とけい</rt></ruby>　<ruby>刻<rt>きざ</rt></ruby>む<ruby>命<rt>いのち</rt></ruby>
>
> *失准的时钟 印刻的生命*

::: definition
- **狂（くる）った**：五段动词「狂う」（发狂、失常）的「た形」，作连体修饰，直接接在名词「時計」前。
- **刻（きざ）む**：五段动词，连体形修饰「命」。刻む＝刻、铭刻。
- **体言止め**：整句只有「连体修饰＋名词」的并列，没有谓语。歌词常用名词结句，留下余韵。
:::

> こぼれてく<ruby>記憶<rt>きおく</rt></ruby>の<ruby>砂<rt>すな</rt></ruby>
>
> *指间流逝的记忆之砂*

::: definition
- **こぼれてく**：「こぼれる」（溢出、洒落）的て形＋补助动词「いく」的缩约形「てく」。こぼれていく→こぼれてく，表示「不断地…下去」。
- **の**：连体助词，连接「記憶」与「砂」，表内容／所属。
- **体言止め**：同样以名词结句。
:::

> <ruby>芽生<rt>めば</rt></ruby>えた<ruby>想<rt>おも</rt></ruby>いまで
>
> *就连萌生的思念*

::: definition
- **芽生（めば）えた**：下一段动词「芽生える」（萌芽）的た形，连体修饰「想い」。
- **まで**：副助词，表「连…都」，暗示范围之广——连刚刚萌生的思念也不例外。
:::

> ねえ こんなに<ruby>呆気<rt>あっけ</rt></ruby>なく
>
> *你看 如此轻易*

::: definition
- **ねえ**：感叹词，唤起对方注意，相当于「喂／你看」。
- **こんなに**：副词，表程度，＝这么、如此。
- **呆気（あっけ）なく**：イ形容词「呆気ない」（轻易的、扫兴的）的连用形（く形），修饰下一句的「消えてしまう」。
:::

> <ruby>消<rt>き</rt></ruby>えてしまうの
>
> *便烟消云散*

::: definition
- **消（き）えて**：下一段动词「消える」（消失）的て形。
- **しまう**：补助动词，接て形后，表「彻底…了／（遗憾地）…了」。
- **の**：终助词，句末表感叹、说明语气，相当于「のだ」的柔和说法。
:::

> I wish I was there
>
> *我如此希望曾伴你而行*

## Chorus 1 副歌

> Oh, please don't let me die
>
> *请不要让我就此死亡*

> Waiting for your touch
>
> *静候与你的再度邂逅*

> <ruby>二度<rt>にど</rt></ruby>となにも<ruby>失<rt>な</rt></ruby>くさぬように
>
> *为了不再失去手中之物*

::: definition
- **二度（にど）と**：副词，必须与否定呼应，＝再也不…。
- **なにも**：＝何も，与否定呼应，＝什么都（不）…。
- **失（な）くさぬ**：五段动词「失くす」（＝失う，失去）的未然形「失くさ」＋否定助动词「ぬ」（＝ない，书面语）。失くさぬ＝不失去。
- **ように**：接否定／非意志性表达后表目的，＝为了…。肯定且带意志的动词则用「ために」。
:::

> <ruby>私<rt>わたし</rt></ruby>を<ruby>忘<rt>わす</rt></ruby>れて　<ruby>始<rt>はじ</rt></ruby>めて　"Restart"
>
> *遗忘我的存在 开始旅途 “重新开始”*

::: definition
- **私（わたし）を**：を 提示宾语。
- **忘（わす）れて**：下一段动词「忘れる」的て形。
- **始（はじ）めて**：下一段动词「始める」（开始）的て形。
- **て形中止法**：两个动作都用て形，表示顺接／并列——「忘掉我，然后重新开始」。
:::

> No, don't  give up on life
>
> *不 不要放弃生存的希望*

> This endless dead end
>
> *永无止境的死亡早已远去*

> <ruby>君<rt>きみ</rt></ruby>を<ruby>砕<rt>くだ</rt></ruby>くこの<ruby>悲<rt>かな</rt></ruby>しみが
>
> *愿那令你痛苦无比的悲伤*

::: definition
- **君（きみ）を**：宾语。
- **砕（くだ）く**：五段动词（粉碎、击碎）的连体形，修饰「悲しみ」。
- **この**：连体词。
- **が**：主格助词，提示主语「この悲しみ」。谓语在下一句「終わりますように」。
:::

> いつか<ruby>終<rt>お</rt></ruby>わりますように
>
> *有迎来终结的一天*

::: definition
- **いつか**：副词，总有一天、不知何时。
- **終（お）わります**：五段动词「終わる」的ます形。
- **ように**：接ます形／辞书形后表祈愿，＝希望…、愿…。常见句型「〜ますように」。
:::

> For now, I'll see you off
>
> *为此 我将会目送你的离去*

> <ruby>甘<rt>あま</rt></ruby>い<ruby>香<rt>かお</rt></ruby>り<ruby>放<rt>はな</rt></ruby>つ
>
> *追寻着散发出香甜气息之物*

::: definition
- **甘（あま）い**：イ形容词，连体修饰「香り」。
- **香（かお）り**：名词，香气。
- **放（はな）つ**：五段动词（散发）的连体形。原本应说「香りを放つ」，这里省略了「を」。
- **跨行连体修饰**：这一句整体「甘い香り放つ」修饰下一句的「追憶」，＝散发着甜美香气的追忆。
:::

> <ruby>追憶<rt>ついおく</rt></ruby>という<ruby>名<rt>な</rt></ruby>の<ruby>罠<rt>わな</rt></ruby>
>
> *哪怕已然知晓其为陷阱*

::: definition
- **という**：表命名、引用，＝叫做…的。
- **名（な）の**：名词＋の 连接「罠」，＝名为…的陷阱。
- **体言止め**：以名词结句。
:::

> <ruby>誘<rt>さそ</rt></ruby>われ<ruby>囚<rt>とら</rt></ruby>われ
>
> *被其诱惑住 又被囚禁住*

::: definition 
- **誘（さそ）われ**：五段动词「誘う」（引诱、邀请）的被动形「誘われる」的连用形。
- **囚（とら）われ**：下一段动词「囚われる」（被囚禁）的连用形。
- **受身＋连用形中止法**：两个被动动作并列，主语（私が）被省略。
:::

> なぜ<ruby>抗<rt>あらが</rt></ruby>えもせず また
>
> *但是为何 在还未能反抗之时*

::: definition 
- **なぜ**：疑问副词，为什么。
- **抗（あらが）えもせず**：「抗う」（反抗）的可能形「抗える」的连用形「抗え」＋「も」＋「せず」。「せず」是「する」的否定连用形（＝しないで）。整句＝连反抗都做不到。
- **また**：副词，又。
:::

> <ruby>溺<rt>おぼ</rt></ruby>れてしまうの
>
> *却又沉溺于其中了呢……*

::: definition 
- **溺（おぼ）れて**：下一段动词「溺れる」（沉溺）的て形。
- **しまう**：补助动词，表「彻底…了／（遗憾地）…了」。
- **の**：终助词，表感叹、说明语气。
:::

> I wish you were here
>
> *我如此希望你会为我而驻足*

- **見失（みうしな）う**：五段动词，看丢、跟丢。
- **て形中止法**：两个动作并列／顺接。

## Bridge 间奏

> ...fading in, fading out...……
>
> *似近似远 似有似无……*

> I wish we were there
>
> *我如此希望我们都在为彼此而等待*

> あの<ruby>日々<rt>ひび</rt></ruby>には<ruby>戻<rt>もど</rt></ruby>れない
>
> *哪怕是回溯 也无法挽回过往的时光*

::: definition 
- **あの日々（ひび）**：那些日子。
- **には**：に（归着点，「戻る」的对象用 に）＋は（强调／对比）。
- **戻（もど）れない**：五段动词「戻る」的可能形「戻れる」的否定形，＝回不去。
:::

> <ruby>時<rt>とき</rt></ruby>は<ruby>強<rt>つよ</rt></ruby>く　<ruby>哀<rt>かな</rt></ruby>しく<ruby>強<rt>つよ</rt></ruby>く
>
> *重叠着的时间 如此让人濒临崩溃*

::: definition 
- **時（とき）は**：は 提示主题。
- **強（つよ）く／哀（かな）しく**：イ形容词「強い」「哀しい」的连用形（く形）。
- **连用形中止法**：两个形容词并列，后面省略了谓语，留下余韵。
:::

> ただただ<ruby>進<rt>すす</rt></ruby>んでゆくだけ　"Restart"
>
> *不过 只能继续面对这死循环般的死局 “重新开始”*

::: definition 
- **ただただ**：副词「ただ」的重复，加强语气，＝只是一味地。
- **進（すす）んで**：五段动词「進む」的て形。
- **ゆく**：补助动词「いく」的书面／文学形式，表示朝某方向持续进行。
- **だけ**：副助词，表限定，＝只是…。
:::
