# TRY! N5 Unit 5(1)

## ２３　上手になりました

”～く／に なります”表示某种状态自然而然地发生变化

| い形容词 | い变く+なります |
| -------- | --------------- |
| な形容词 | +に+なります    |
| 名词     | +に+なります    |

”～く／に します”表示某种状态人为地发生变化

| い形容词 | い变く+します |
| -------- | ------------- |
| な形容词 | +に+します    |
| 名词     | +に+します    |



## ２４　読みたいです

"～たいです", 表达自身的欲望或希望

ます形去ます+たいです



## ２５　読みたいですから、…

”から”, 用于说明理由或原因



## ２６　漫画が好きです

愿望/能力/喜恶使用"が"引出对象, 另见[语法10](./n5-unit3-1.md#１０　ほしいです)



## ２７　見に行きませんか

"～に行きます", 因为某种目的去某地, 也有"～に来ます""～に帰ります"

ます形去ます+に+行きます

名词+に+行きます
