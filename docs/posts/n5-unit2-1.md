# TRY! N5 Unit 2(1)

## １　あります

表示现在或将来的事物时, 使用"～です""～ます"

|          | 现在肯定形 | 现在否定形                    |
| -------- | ---------- | ----------------------------- |
| 动词     | 动词ます形 | ～ます→～ません               |
| い形容词 | +です      | 词尾"い"变"くない"+です       |
| な形容词 | +です      | +ではありません／じゃないです |
| 名词     | +です      | +ではありません／じゃないです |



## ２　ありますか

提问时, 在句末加"か"

回答一般疑问句时, 才能使用"そうです""違います"



## ３　どこですか

### 疑问词

だれ／どなた　谁/哪位

どこ／どちら　哪里

なに／なん　什么

どうして／なぜ　为什么

どれ　哪个

どの+名词　哪个...

どちら／どっち　哪(一)个

どう／いかが　怎么样/如何

どんな+名词　什么样的...

いつ　何时

なんで　为什么

どうやって　怎么样

いくら　多少钱



### 根据疑问词的位置选择使用”は”或”が”

A: ～は、疑问词+か。

B: ～は、…です。



A: 疑问词+が、～か。

B: …が、～です。



### どうですか

更礼貌的说法是いかがですか

也可用于劝诱对方做某事



## ４　あちらです

指示事物, 地点, 方向时, 使用”これ””それ””あれ”

| 事物      | これ           | それ           | あれ           | どれ？           |
| --------- | -------------- | -------------- | -------------- | ---------------- |
| 事物      | この+名词      | その+名词      | あの+名词      | どの+名词？      |
| 地点      | ここ           | そこ           | あそこ         | どこ？           |
| 地点/方向 | こちら／こっち | そちら／そっち | あちら／あっち | どちら／どっち？ |
