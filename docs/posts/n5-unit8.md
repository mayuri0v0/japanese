# TRY! N5 Unit 8

## ４０　午後、忙しい？

### 简体形

#### い形容词

敬体形去掉です即可

#### 动词

| 敬体形           | 简体形           |
| ---------------- | ---------------- |
| 行きます         | 行く(原形)       |
| 行きません       | 行かない(ない形) |
| 行きました       | 行った(た形)     |
| 行きませんでした | 行かなかった     |

#### な形容词/名词

| 敬体形                 | 简体形         |
| ---------------------- | -------------- |
| 雨です                 | 雨だ           |
| 雨じゃないです         | 雨じゃない     |
| 雨でした               | 雨だった       |
| 雨じゃありませんでした | 雨じゃなかった |



## ４１　鈴木君、午後、忙しい？

省略不影响句意的助词, 如"は"”が””を””へ”



## ４２　授業はないけど、…

”けど”相对于”が”更加非正式



## ４３　もう食べた

计划要做的事, 或想做的事已经完成, 使用”もう～ました／た”

もう+动词过去式



## ４４　まだ食べていない

”まだ～ていません／いない”表示想要做的事还未做

句型是客观描述

主观描述自己"不想吃"使用「まだ食べません」



## ４５　木がたくさんある公園

简体形+名词, 其中简体形整体做定语, 从句中的主语使用”が／の”
