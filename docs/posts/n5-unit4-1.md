# TRY! N5 Unit 4(1)

## １５　行きませんか

邀请别人时, 使用”～ませんか”

ます形去ます+ませんか



## １６　面白いところですよ

表告知, 使用”よ”



## １７　駅の前

事物+の+方位词



## １８　公園があります

ある／いる表存在, 一个用于无生命物体, 一个用于有生命物体

1. 地点+に+事物+が　あります
2. 地点+に+人/动物+が　います
3. 事物+は+地点+に　あります
4. 人/动物+は+地点+に　います



## １９　行きましょう

劝诱他人做某事, 使用”～ましょう”

ます形去ます+ましょう



ませんか用于询问对方心意

ましょう表示下定决心或想要呼吁他人一同做某事
